## Overview

**FinAI** is an educational and practical student finance project developed by **Anil Pandey** in **London, United Kingdom**. It combines **Business Analytics**, **Python Data Analysis**, and **Artificial Intelligence (AI)** to help university students track expenses, understand cash-flow runway, and make informed budgeting decisions across the academic term.

## Core Analytical Features

1. **Automated Expense Categorisation (Python):** Structures raw CSV transaction exports into student-specific budget categories.
2. **Student Cash-Flow Metrics (Business Analytics):**
   - **Term Runway:** Projects how many weeks a student's balance will last at their current daily burn rate.
   - **Budget Variance Analysis:** Compares planned weekly category budgets against actual spending.
3. **Plain-Language Weekly Insights (AI Agents & Automation):** Formats structured variance tables for AI summarization workflows.
